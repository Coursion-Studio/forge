Parallel subagents

Watch every subagent work, live.

  • Cards or one activity feed beside the conversation.
  • Honest status. "Queued for the build lock, 2m" instead of a spinner that says "Starting".
  • The Agents window (⌘⇧G) shows every pane and subagent across all projects, with cost and run-time warnings.
  • The right model per job. Scouts on Haiku, builders on Sonnet, reviewers on Opus.

Proof, then ship

Agents prove their work before it lands.

"Tests pass" has to be true for the exact commit handed back. Then Forge lands the branch and cleans up after it.

  • Verified hand-backs. A subagent's "done" is checked against a green run of that exact tree, or sent back.
  • One-click Land. Rebase on main, run your gate, fast-forward, bump the build, remove the worktree.
  • Failures go back to the agent that owns the branch, with the failing lines.
  • Install when idle. Your app rebuilds itself only once every agent has stopped working.

Questions

Who is Forge for?

Developers on a Mac who already work with coding agents like Claude Code and want several of them on real projects, with terminals, a board and test VMs right beside them. It is built for iOS, web and Mac projects.

Do I need an API key?

Not for Claude Code. Forge runs the Claude Code you already have, signed in with your own account. Any other keys your projects need stay in your Keychain.

Does my code leave my Mac?

Only what your agent sends to its model provider, exactly as when you run Claude Code in a terminal. Forge puts no server of its own between you and your code.

How do the test VMs work?

Forge runs app and UI tests inside throwaway macOS virtual machines on your own Mac, so agents can launch apps, boot simulators and take screenshots without touching your screen.

Is it Mac only?

Yes. Forge is a native Mac app and needs macOS 15 (Sequoia) or later.
