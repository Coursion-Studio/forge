The harness

Agents can't just say “done”.

Forge wraps Claude Code in a harness. Every job gets the right model, its own worktree and a clear finish line, and a hook turns back any “done” that has no green test run on the exact commit it hands you.

  • Proof, not promises. A hand-back needs a passing forge-verify on that exact tree. Edit after testing and it goes back.
  • The right model for each job. Haiku searches, Sonnet builds, Opus reviews, Fable takes the hard ones. Every launch says which and why.
  • Its own worktree. Workers never touch your checkout. A reviewer and a tester check the branch before it lands.
  • Briefs with a finish line. A brief without “Done when” bounces before the agent starts.
  • Nothing left behind. A janitor clears merged worktrees, stale builds and test simulators.
Parallel subagents

Watch every subagent work, live.

When Claude splits a job, each subagent gets a card: its model, its worktree, the step it is on and what it costs. No guessing what is running.

  • Cards or one activity feed beside the conversation.
  • Honest status. "Queued for the build lock, 2m" instead of a spinner that says "Starting".
  • The Agents window (⌘⇧G) shows every pane and subagent across all projects, with cost and run-time warnings.
  • The right model per job. Scouts on Haiku, builders on Sonnet, reviewers on Opus.

Questions

Who is Forge for?

Developers on a Mac who already work with coding agents like Claude Code and want several of them on real projects, with terminals, a board and test VMs right beside them. It is built for iOS, web and Mac projects.

Do I need an API key?

Not for Claude Code, Codex or Cursor Agent. Forge runs the ones you already have, signed in with your own accounts. aider, the AI chat and any keys your projects need stay in your Keychain.

Which agents does Forge support?

Claude Code, Codex, Cursor Agent and aider, side by side in one workspace. Claude Code gets the native UI, subagent cards and the full harness with proof-gated hand-backs. The AI chat and Compare panes take Anthropic, OpenAI, Moonshot or a local Ollama model.

Does my code leave my Mac?

Only what your agent sends to its model provider, exactly as when you run Claude Code in a terminal. Forge puts no server of its own between you and your code.

How do the test VMs work?

Forge runs app and UI tests inside throwaway macOS virtual machines on your own Mac, so agents can launch apps, boot simulators and take screenshots without touching your screen.

Is it Mac only?

For now. Forge starts as a native Mac app for macOS 15 (Sequoia) or later. Windows and Linux versions are planned. Join the waitlist and you will hear when they open.

When does it open?

We are inviting people from the waitlist in small groups. Join and you will get one email when your invite is ready.
